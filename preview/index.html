_LEDGER/

Always balanced

A double-entry ledger built for engineers.

Model any money movement with CreditScript. Every transaction is atomic, immutable, and reconciled by construction, so your books never drift, even at scale.

creditscript 
send [USD 100] (
  source = @world
  destination = {
    85% to @sellers:acme
    15% to @platform:fees
  }
)
workflow.yaml 
name: collect_and_disburse
stages:
  - send:
      destination:
        account: orders:1234
      amount:
        asset:  USD/2
        amount: 599
